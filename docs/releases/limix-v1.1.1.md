## 核验结果

| 检查 | 结果 |
|---|---|
| 实际 EXE 冻结概率回放 | 5 件示例，类别均与原 GPU 基准一致；概率最大绝对差 0.000653405，低于预设 0.001 容差 |
| 实际 EXE 界面分析及导出 | PASS；5 行概率、样品/地区/文献各 20 行检索结果，Excel 正常 |
| 缺测距离定义 | PASS；不同缺测组合与逐项实测维度 RMS 公式一致；未测元素变化不影响距离 |
| 源码 CPU 完整输入 | PASS；63 件、各 36 项测量，概率有限且和为 1，检索与 Excel 导出正常 |
| 源码 CPU 缺测输入 | PASS；36 件、各 22 项测量，概率有限且和为 1，检索与 Excel 导出正常 |

完整与缺测两批源码检查共耗时约 25.85 秒，包含一次模型加载；运行时间依机器而变。

本次修复了缺测检索距离误计未测元素的问题，并在 CPU 上禁用不兼容的自动混合精度；GPU 路径保持原设置。CPU/GPU 存在小幅浮点差异，不应把二者表述为概率逐位相同。

以上是程序回放、输入处理和导出核验，不是独立地质验证准确率。
