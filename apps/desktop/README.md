# D36 未知样品构造环境判别工具

双击桌面上的 **D36构造环境判别工具** 即可启动。

## 输入

- CSV、TXT 或 XLSX；
- 每行一个未知样品；
- 必须包含36个D36元素列，列名见工具导出的空白模板；
- `Sample_ID` 可省略；`Latitude` 和 `Longitude` 可省略；
- 所有36个元素必须为有限正数；一次最多500个样品。

## 输出

1. 每个样品属于 BAB、CA、CFB、CR、IA、IOA、MOR、OI、OP 的九类概率；
2. 整组未知样品与训练库全部地区的化学相似度完整排名；
3. 整组未知样品与训练库全部文献的化学相似度完整排名；
4. Excel中另有逐样品地区/文献Top-20与审计JSON。

工具默认使用纯化学D36_74。经纬度空间先验默认关闭，只有用户主动勾选且经纬度完整时才启用；坐标缺失精确回退D36_74。有效输入样品不拒识。

相似指数仅用于化学空间排序，不是地区或文献来源概率。定义为：对36元素取log10，候选组内取最近3个样品的RMS距离，多未知样品再平均，最后显示 `100 × 10^(-距离)`。
