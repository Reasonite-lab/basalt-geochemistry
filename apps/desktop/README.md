# D36 未知样品构造环境判别工具

双击 **D36Predictor.exe** 即可启动（Windows 10/11 64 位，无需安装 Python）。

## 输入

- CSV、TXT 或 XLSX；
- 每行一个未知样品；
- 元素列名见工具导出的空白模板；**留空表示缺测**；
- 最低覆盖：全部 10 项主量氧化物 + 任意 8 项微量元素（共 ≥ 18 项实测）；
- 已测量的元素必须为有限正数；`Sample_ID` 可省略；`Latitude` 和 `Longitude` 可省略；
- 一次最多 500 个样品。

## 输出

1. 每个样品属于 BAB、CA、CFB、CR、IA、IOA、MOR、OI、OP 的九类概率（含实测元素数、归一化熵）；
2. 整组未知样品与训练库全部地区的化学相似度完整排名；
3. 整组未知样品与训练库全部文献的化学相似度完整排名；
4. Excel 中另有逐样品地区/文献 Top-20 与审计 JSON。

工具默认使用纯化学 D36_74（缺测感知）。经纬度空间先验默认关闭，只有用户主动勾选且经纬度完整时才启用；坐标缺失精确回退 D36_74。有效输入样品不拒识。

缺测预测使用 LightGBM 原生 NaN 协议（训练时加入微量遮挡增强），缺测样品的置信度未单独重新标定，请结合样品背景解释。

相似指数仅用于化学空间排序，不是地区或文献来源概率。定义为：对实测元素取 log10，候选组内取最近 3 个样品的 RMS 距离（仅按实测元素计算），多未知样品再平均，最后显示 `100 × 10^(-距离)`。

模型状态：GeoSinglePrior-D36-v2 冻结推理包（expansion13，16,455 个非零值样品训练）。
