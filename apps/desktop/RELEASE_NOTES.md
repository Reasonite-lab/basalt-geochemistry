# D36 构造环境判别工具 1.1.0

本版更新模型并接入缺测样品预测。

- 模型更新为 GeoSinglePrior-D36-v2：在 expansion13 冻结数据（16,459 条；其中 4 条 GEOROC 未检出填零样品排除，实际训练 16,455 条）上重新训练三成员 LightGBM 集成，训练时加入微量遮挡增强。
- 新增缺测预测：元素留空表示缺测，使用 LightGBM 原生 NaN 协议；最低要求全部 10 项主量加任意 8 项微量（共 ≥ 18 项实测）。参考不完整组合实验（D18/D22）的下限。
- 化学相似度检索改为仅按实测元素计算距离。
- 九类概率表新增“实测元素数”列；审计 JSON 记录缺测协议与最低覆盖。
- 经纬度先验默认关闭；手动启用且坐标有效时才参与预测。
- 一次最多 500 件；CSV/TXT/XLSX 导入、手工录入、示例数据及空白模板不变。
- 仍是软件正确性检查通过（冻结概率回放、可执行文件真实推理与导出、界面冒烟），不代表未知地区预测准确率；缺测输入的置信度未单独重新标定。
- LimiX-2M 与同位素输入接入属于后续开发，见 docs/roadmap.md。

下载后先完整解压到可写文件夹，再启动程序。`SHA256SUMS.txt` 可核对下载完整性。
