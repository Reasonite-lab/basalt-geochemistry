# D36 构造环境判别工具 1.0.2

沿用原桌面版本的中文界面与离线推理功能，首次提供 GitHub 可下载发行包及可复现打包流程。

- Windows 10/11 64 位便携版：解压后双击 `D36Predictor.exe`，无需安装 Python。
- CSV/TXT/XLSX 导入、手工录入、示例数据及空白模板。
- 九类构造环境概率、地区与原始文献化学相似度检索、Excel 和审计 JSON 导出。
- 经纬度先验默认关闭；手动启用且坐标有效时才参与预测。
- 模型仍为原冻结的三成员 LightGBM 集成；本版未改动模型权重。
- 要求完整的 36 项正数元素测量，一次最多 500 件。LimiX-2M、同位素输入和缺测预测尚未接入该桌面版本。

发行检查包括冻结概率回放、可执行文件真实推理和导出、Tk 界面载入示例与分析。它们是软件正确性检查，不代表未知地区的预测准确率。

下载后先完整解压到可写文件夹，再启动程序。`SHA256SUMS.txt` 可核对下载完整性。
